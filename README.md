# Домашнее задание к работе 2

## Условие задачи
В течение месяца продавец доставлял на дом 4 л. молока в день. В марте молоко стоило **x** руб. за литр. С первого апреля цена молока увеличилась на **(x + a)** руб. за литр. Сколько надо заплатить продавцу за все доставленное молоко в конце апреля? Количество покупаемого молока осталось прежним.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Задать исходные данные:
   - `x` = 50 золотых - Стоимость погонного метра.
   - `s` = 400 м² — Площадь парусов.
   - `l` = 100 см — Ширина ткани в рулоне.
4. Вычислить длину паруса:
   - `length` = `s` / (l / 100);
5. Вычислить, сколько Грей заплатил ткань для своей бригантины:
   - `price` = `length` * `x`;
6. Вывести результаты расчетов с подстановкой всех значений в текст.
7. **Конец**

## 2. Реализация программы

```c#include <stdio.h>
#include <locale.h>
void main() {
	//Задание № 15
	setlocale(LC_ALL, "RUS");
	int x, s, l, price, length;
	x = 50;
	s = 400;
	l = 100;
	length = s / (l / 100);
	price = length * x;
	printf("Грей заплатил за %d метров ткани %d золотых", length, price);
}```
